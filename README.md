# Katman MQTT Client downloads

Official desktop packages and release notes for Katman MQTT Client.

**[Download Katman MQTT Client](https://www.katmanmqtt.com/download)**

Linux x86_64 packages are available as AppImage, Debian (`.deb`), and RPM (`.rpm`). Windows and macOS packages are coming later.

Each release includes SHA-256 checksums. AppImage packages include signatures for the application's built-in updater. Debian and RPM installations are managed through your system's package manager.

This repository contains distribution files and public documentation. Application source is maintained privately. Publishing a package here does not grant an open-source license to the application.

Visit [katmanmqtt.com](https://www.katmanmqtt.com) for product information and support.
